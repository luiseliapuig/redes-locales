# Redes locales

Repositorio de materiales y herramientas web para el módulo de Redes locales.

El objetivo es reunir en un único lugar los recursos web propios utilizados durante el curso, manteniéndolos independientes de Moodle y fáciles de actualizar y reutilizar.

## Principio general

Todo el contenido de este repositorio debe poder ejecutarse directamente en un navegador.

Las piezas se desarrollarán con:

- HTML
- CSS
- JavaScript

Siempre que sea posible se evitarán dependencias, procesos de compilación, frameworks y cualquier infraestructura innecesaria.

La prioridad es que cada recurso sea:

- sencillo;
- autónomo;
- fácil de mantener;
- fácil de desplegar;
- reutilizable desde Moodle mediante un enlace.

## Estructura inicial

    /
    ├── index.html
    ├── herramientas/
    ├── glosarios/
    ├── materiales/
    ├── README.md
    └── AGENTS.md

### `herramientas/`

Aplicaciones y utilidades interactivas para trabajar contenidos de Redes locales.

Por ejemplo:

- conversión binario/decimal;
- práctica de direccionamiento IPv4;
- subnetting;
- calculadoras;
- simuladores;
- entrenadores y ejercicios autocorregidos.

### `materiales/`

Materiales web de apoyo y ampliación.

Aquí se alojarán, entre otros, los contenidos enlazados desde los botones **Més informació** del curso.

### `glosarios/`

Materiales de consulta rápida y referencia, como glosarios de comandos y conceptos de Redes locales.

## Índice general

`index.html` es el mapa general del repositorio.

Cada nueva herramienta, material o glosario que se incorpore al proyecto deberá añadirse también al índice.

El índice debe permitir localizar y abrir fácilmente todas las piezas disponibles.

## Relación con Moodle

Moodle es la estructura docente del curso: organiza los bloques, actividades, entregas, cuestionarios, calificaciones y seguimiento.

Este repositorio aloja los recursos web propios.

Moodle enlazará estos recursos, pero no será necesario subir una nueva copia a Moodle cada vez que se actualicen.
