01 · Conceptos básicos

¿Qué es una dirección IPv4?

Una dirección IPv4 es un identificador lógico de 32 bits que se utiliza para identificar una interfaz de red y dirigir datos hacia ella. Normalmente se escribe como cuatro números decimales separados por puntos.

4 octetos × 8 bits = 32 bits · Cada octeto puede valer de 0 a 255

01111100 . 00010111 . 00000110 . 00101110

Esta es la misma dirección escrita en binario. Cada grupo de ocho dígitos representa un octeto.

Una IP no identifica necesariamente a un ordenador entero: un equipo puede tener varias interfaces y, por tanto, varias direcciones IP.
02 · Identificar las partes

La máscara separa red y host

La dirección IP contiene una parte de red (identifica a qué red pertenece) y una parte de host (identifica una interfaz dentro de esa red). La máscara indica dónde está la separación.

Notación CIDR

/8, /16 y /24 indican cuántos bits de la dirección pertenecen a la red. Por ejemplo, /24 significa 24 bits de red y 8 de host.

Máscara decimal

/8 → 255.0.0.0
/16 → 255.255.0.0

03 · Direcciones que debes reconocer

Red, broadcast y loopback

Dirección de red

Identifica el bloque de direcciones. Se obtiene poniendo todos los bits de host a 0. En las subredes IPv4 convencionales no se asigna a los equipos.

¿Cuántos hosts utilizables tiene esta red?

Otra dirección especial: loopback. 127.0.0.1 se utiliza para comunicarse con el propio equipo. No es la dirección de red ni la dirección de broadcast de tu LAN.
04 · Del bloque a los hosts

Calcular las direcciones útiles

Una vez identificadas la dirección de red y la de broadcast, podemos encontrar las direcciones que normalmente se asignan a los dispositivos.

¿Por qué restamos 2?

Con 8 bits de host existen 2⁸ = 256 combinaciones. En una subred IPv4 convencional reservamos una para la dirección de red y otra para broadcast.

256 − 2 = 254 hosts utilizables.

¿Y con otras máscaras?

/8 → 24 bits de host → 16.777.214 hosts
/16 → 16 bits de host → 65.534 hosts
/24 → 8 bits de host → 254 hosts

Son los casos básicos de esta unidad; existen máscaras especiales como /31 y /32 con reglas diferentes.

Para encontrar la dirección de red en general se aplica una operación AND bit a bit entre la IP y la máscara. En /8, /16 y /24 podemos reconocer el resultado mirando los octetos.
05 · Comprobar pertenencia

¿Están en la misma red?

Dos direcciones pertenecen a la misma subred cuando, al aplicar su máscara, obtenemos la misma dirección de red. Que las IP se parezcan no basta: también importa la máscara.

Regla práctica

1
Identifica la máscara de las dos interfaces.
2
Calcula la dirección de red de cada una (IP AND máscara).
3
Compara los resultados: si coinciden, están en la misma subred; si no, en subredes diferentes.
