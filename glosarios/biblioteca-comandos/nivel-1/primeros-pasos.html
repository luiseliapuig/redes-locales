Nivel 1 · Etapa 1 — Descubrir la terminal

Primeros pasos con la terminal

En Linux y en Windows, una terminal es una ventana desde la que puedes dar instrucciones al ordenador escribiendo comandos. Sirve para consultar información, recorrer carpetas y administrar el sistema. Escribe una orden y pulsa Intro para ejecutarla.

Linux

Abre la aplicación Terminal. Los ejemplos se orientan a una consola habitual con Bash y utilidades GNU. Respeta mayúsculas y minúsculas en los nombres.

Windows CMD

Abre Símbolo del sistema buscando cmd en Inicio. Windows Terminal puede alojar varias consolas: selecciona el perfil Símbolo del sistema para estos ejemplos.

Consulta primero los ejemplos de Linux y después los de Windows CMD. Las etiquetas indican dónde usar cada orden. PowerShell tiene sus propios comandos y no se trata en esta etapa.

A. Identificar B. Navegar C. Organizar D. Consultar ayuda

A. Identificar el entorno

Linux Windows CMD

Identificar al usuario Consultar

Linux Muestra el usuario actual
Windows CMD Muestra el usuario actual

Muestra el usuario con el que se ejecuta el comando.

Fíjate en: en Linux aparece el nombre del usuario efectivo; en CMD suele aparecer equipo\usuario o dominio\usuario.

Identificar el equipo Consultar

Linux Muestra el nombre del equipo
Windows CMD Muestra el nombre del equipo

Muestra el nombre del equipo.

Fíjate en: es el nombre del ordenador, no el del usuario ni su dirección IP.

Consultar información del sistema Consultar

Linux Muestra información del kernel y la máquina
Windows CMD Muestra la versión de Windows

Consulta información básica del sistema que estás utilizando.

Fíjate en: el nombre y la versión que aparecen en la salida.

Diferencias: uname -a informa sobre el kernel y la máquina; ver muestra la versión de Windows. No ofrecen los mismos datos; la versión del kernel tampoco es la de la distribución.

B. Saber dónde estamos y movernos

Linux Windows CMD

Primero localiza dónde estás; después elige qué quieres hacer. En Linux las rutas usan /; en CMD, \. Para nombres con espacios, usa comillas: cd "Mis apuntes".

Consultar el directorio actual Consultar

Linux Muestra el directorio actual
Windows CMD Sin argumentos, muestra el directorio actual

Muestra la ruta del directorio en el que estás trabajando.

Fíjate en: la ruta completa, por ejemplo /home/alumno/Documentos o C:\Users\alumno\Documentos.

Diferencias: en Bash, cd sin argumentos te lleva a tu carpeta personal; en CMD muestra la ruta sin cambiar de carpeta.

Listar archivos y carpetas Consultar

Linux Lista archivos y carpetas Incluye ocultos y muestra detalles
Windows CMD Lista archivos y carpetas Incluye archivos ocultos y de sistema

Lista el contenido del directorio actual.

Fíjate en: los nombres que aparecen; en CMD, <DIR> identifica las carpetas.

Diferencias: ls muestra normalmente los nombres y omite los que empiezan por punto. dir añade fechas y tamaños, y omite por defecto archivos ocultos y de sistema.

Cambiar de directorio

Linux Entra en la carpeta Documentos
Windows CMD Entra en la carpeta Documentos

Entra en la carpeta indicada. En este ejemplo, Documentos debe existir dentro del directorio actual.

Fíjate en: la nueva ubicación; consúltala con pwd en Linux o cd sin argumentos en CMD.

Diferencias: Linux distingue mayúsculas y minúsculas; CMD normalmente no. En CMD, cd /d D:\Practicas cambia también de unidad si esa ruta existe.

Subir al directorio superior

Linux Sube al directorio superior
Windows CMD Sube al directorio superior

Sube un nivel en la estructura de carpetas.

Fíjate en: cómo cambia la ruta: de Documentos pasas a la carpeta que la contiene. Compruébalo con pwd en Linux o cd en CMD.

Ir al directorio raíz

Linux Va a la raíz del sistema de archivos
Windows CMD Va a la raíz de la unidad actual

Va al inicio de la jerarquía de directorios correspondiente.

Fíjate en: la ruta resultante: / en Linux; por ejemplo, C:\ en CMD si trabajabas en esa unidad.

Diferencias: Linux tiene una raíz común del sistema de archivos. En CMD vas a la raíz de la unidad actual; no cambias de unidad.

C. Crear y organizar carpetas

Linux Windows CMD

Son ejemplos independientes con nombres ficticios. Para copiar o mover, notas.txt y la subcarpeta Practicas deben existir en el directorio actual. Usa nombres de destino nuevos para conservar los archivos existentes.

Crear una carpeta

Linux Crea la carpeta Practicas
Windows CMD Crea la carpeta Practicas

Crea una carpeta llamada Practicas en el directorio actual.

Fíjate en: comprueba que aparece con ls en Linux o dir en CMD.

Eliminar una carpeta vacía

Linux Elimina la carpeta Temporal si está vacía
Windows CMD Elimina la carpeta Temporal si está vacía

Elimina la carpeta Temporal. En estos ejemplos solo funciona si está vacía.

Fíjate en: Temporal debe existir, estar vacía y no ser tu directorio actual. Después dejará de aparecer en el listado.

Copiar un archivo

Linux Copia el archivo y pregunta antes de sobrescribir
Windows CMD Copia el archivo en Practicas

Crea una copia del archivo; el original permanece en su ubicación.

Fíjate en: en el origen notas.txt y en la nueva copia dentro de Practicas.

Diferencias: En Linux, -i solicita confirmación antes de sobrescribir. En CMD, copy normalmente pregunta en uso interactivo, pero depende de la configuración y de si se ejecuta en un script.

Mover un archivo

Linux Mueve el archivo y pregunta antes de sobrescribir
Windows CMD Mueve el archivo a Practicas

Traslada el archivo a Practicas; deja de estar en su ubicación original.

Fíjate en: comprueba que notas.txt aparece en Practicas y ya no en la carpeta de origen.

Diferencias: En Linux, -i pregunta antes de sobrescribir. En CMD, move normalmente pregunta en uso interactivo; la configuración o un script pueden cambiarlo. Usa un destino nuevo.

D. Ayuda y limpieza de pantalla

Linux Windows CMD

Limpiar la pantalla

Linux Limpia la pantalla de la terminal
Windows CMD Limpia la pantalla de CMD

Limpia la información visible de la terminal, sin eliminar archivos.

Fíjate en: la pantalla queda despejada; los archivos y el directorio actual no cambian.

Consultar ayuda Consultar

Linux Abre el manual de ls
Windows CMD Muestra la lista de comandos disponibles Muestra la ayuda de dir

Consulta documentación para conocer la sintaxis y las opciones de un comando.

Fíjate en: la descripción y los argumentos. Leer la ayuda es más útil que memorizar todas las opciones.

Diferencias: En Linux, man abre el manual si está instalado: usa las flechas y pulsa q para salir. Para comandos internos de Bash, como cd, usa help cd. En CMD, help muestra ayuda de comandos internos; muchos comandos admiten /?.

No necesitas memorizarlo todo

Aprender a consultar la ayuda es más importante que recordar todos los comandos. Identifica primero el entorno, revisa la ruta actual y consulta la sintaxis cuando tengas dudas.
