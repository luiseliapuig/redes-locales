Nivel 3 · Etapa 5 — Administrar redes

Switches y VLAN

Aprenderás a reconocer los modos de Cisco IOS, consultar y guardar la configuración de un switch y organizar sus puertos mediante VLAN y enlaces trunk.

Los ejemplos usan un switch Cisco IOS con interfaces FastEthernet, como un Catalyst 2960. Los nombres de interfaz, los comandos disponibles y los permisos pueden variar según el modelo y la versión. Usa las interfaces de tu equipo o práctica.

¿Ya conoces los comandos? Consulta el glosario rápido Cisco IOS.

A. Conocer los modos de Cisco IOS

Cisco IOSSwitch

El indicador muestra el contexto: Switch> EXEC usuario; Switch# EXEC privilegiado; Switch(config)# configuración global; Switch(config-if)# configuración de interfaz; Switch(config-vlan)# configuración de VLAN. Los comandos disponibles dependen del modo.

Cambiar de modo

Cisco IOS Desde EXEC usuario, entra en EXEC privilegiado Desde EXEC privilegiado, entra en configuración global Desde un modo de configuración, retrocede un nivel Desde configuración, vuelve a EXEC privilegiado

El indicador cambia al entrar o salir de cada contexto. El acceso privilegiado puede requerir contraseña.

Fíjate en: (config-if) indica que las órdenes afectan a una interfaz; (config-vlan), a una VLAN.

Secuencia de modos · el indicador no se escribeSwitch> enable
Switch# configure terminal
Switch(config)# interface fa0/1
Switch(config-if)# exit
Switch(config)# vlan 10
Switch(config-vlan)# end
Switch#

B. Consultar y guardar la configuración

Cisco IOSSwitch

Consultar la configuración Consultar

EXEC privilegiado · Switch# Muestra la configuración activa Muestra la configuración guardada para el arranque

La configuración activa está en uso; la guardada se utiliza al iniciar el dispositivo. Pueden ser distintas si hay cambios sin guardar.

Fíjate en: el nombre del equipo, las interfaces y los cambios de configuración.

Guardar los cambios Configurar

EXEC privilegiado · Switch# Guarda la configuración activa para el siguiente arranque Alternativa habitual para guardar

Guardar evita perder los cambios de configuración activa al reiniciar. Si se solicita confirmar el nombre de destino, pulsa Intro para aceptar el propuesto.

Importante: en switches Catalyst, las VLAN normales pueden almacenarse por separado en vlan.dat; la conservación y propagación dependen del modelo y del modo VTP.

C. Crear y nombrar VLAN

Cisco IOSSwitch

Crear y nombrar una VLAN Configurar

Configuración global · Switch(config)# Crea o selecciona la VLAN 10 y abre su configuración Configuración VLAN · Switch(config-vlan)# Asigna el nombre ALUMNOS a la VLAN seleccionada

Una VLAN separa lógicamente dispositivos en la red local. El número identifica la VLAN y el nombre ayuda a reconocer su finalidad.

Secuencia completa · creación y consultaSwitch> enable
Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name ALUMNOS
Switch(config-vlan)# end
Switch# show vlan brief

Consultar las VLAN Consultar

EXEC privilegiado · Switch#Lista VLAN y puertos de acceso asociados

Fíjate en: el número 10, su nombre y los puertos de acceso asociados. Los puertos trunk no se interpretan como puertos de acceso de una única VLAN en esta lista.

D. Configurar puertos de acceso

Cisco IOSSwitch

Asignar puertos de acceso a una VLAN Configurar

Configuración global · Switch(config)# Selecciona la interfaz FastEthernet 0/1 Selecciona las interfaces FastEthernet 0/1 y 0/2 Configuración de interfaz o rango Establece el modo de acceso Asigna el puerto o rango a la VLAN 10

Un puerto de acceso conecta normalmente un equipo final y transporta su tráfico de datos sin etiquetar en la VLAN de acceso asignada. Crea primero la VLAN y selecciona la interfaz o el rango adecuado.

Fíjate en: al seleccionar un rango, el indicador es Switch(config-if-range)# y las órdenes se aplican a todas las interfaces seleccionadas.

Secuencia completa · la VLAN 10 debe existirSwitch> enable
Switch# configure terminal
Switch(config)# interface range fa0/1 - 2
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10
Switch(config-if-range)# end
Switch# show vlan brief

E. Configurar enlaces trunk

Cisco IOSSwitch

Configurar un puerto trunk Configurar

Configuración de interfaz · Switch(config-if)#Configura la interfaz seleccionada como trunk

Un trunk puede transportar tráfico de varias VLAN por un enlace, normalmente con etiquetas IEEE 802.1Q. La VLAN nativa normalmente viaja sin etiqueta.

Fíjate en: el puerto debe conectarse a un equipo configurado de forma compatible; los requisitos pueden variar según el modelo.

Secuencia completa · configuración y consultaSwitch> enable
Switch# configure terminal
Switch(config)# interface fa0/24
Switch(config-if)# switchport mode trunk
Switch(config-if)# end
Switch# show interfaces trunk

Consultar los enlaces trunk Consultar

EXEC privilegiado · Switch#Muestra los trunks activos y sus VLAN permitidas

Comprueba el puerto, la VLAN nativa y las listas de VLAN permitidas y activas. Un puerto configurado como trunk puede no aparecer si el enlace no está operativo.

F. Comprobar la configuración

Cisco IOSSwitch

Verificar el switch Consultar

EXEC privilegiado · Switch# ¿Qué VLAN y puertos de acceso aparecen? ¿Qué estado y VLAN muestra cada puerto? ¿Qué trunks están activos y qué VLAN permiten? ¿Qué configuración está activa?

Usa cada vista para responder una pregunta distinta; compara el resultado con las VLAN y puertos que esperabas configurar.

Fíjate en: un puerto desconectado o un trunk inactivo pueden hacer que la salida no coincida con lo esperado.
