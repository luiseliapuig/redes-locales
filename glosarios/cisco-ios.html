Glosario de comandos Cisco IOS

VLANs · Trunk · Inter-VLAN Routing · DHCP · NAT — en orden de uso

Modos de la CLI
Switch Router
enableModo privilegiado
configure terminalModo configuración global
endVuelve al modo privilegiado
exitVuelve al modo anterior
write memoryGuarda la configuración
Creación de VLANs
Switch
vlan 10Crea la VLAN 10
name NOMBREAsigna nombre a la VLAN
show vlan briefLista VLANs y puertos asignados
Asignación de puertos
Switch
interface fa0/1Entra en la interfaz Fa0/1
interface range fa0/1 - 2Varias interfaces a la vez
switchport mode accessPuerto de acceso (una sola VLAN)
switchport access vlan 10Asigna el puerto a la VLAN 10
Enlace trunk
Switch
switchport mode trunkConfigura el puerto como trunk
show interfaces trunkMuestra trunks activos y sus VLANs
Inter-VLAN Routing — router-on-a-stick
Router
interface g0/0Entra en la interfaz física del router
no shutdownActiva la interfaz (imprescindible)
interface g0/0.10Crea la subinterfaz para la VLAN 10
encapsulation dot1Q 10Asocia la subinterfaz a la VLAN 10
ip address 192.168.10.254 255.255.255.0IP que actuará como gateway de la VLAN 10
show ip routeMuestra la tabla de rutas del router
DHCP — servidor en el router
Router
ip dhcp excluded-address 192.168.10.254Reserva una IP para que el router no la reparta
ip dhcp pool NOMBRECrea un pool DHCP con nombre descriptivo
network 192.168.10.0 255.255.255.0Define la subred y máscara del pool DHCP
default-router 192.168.10.254Informa del gateway a los clientes
dns-server 8.8.8.8Informa del servidor DNS a los clientes
show ip dhcp bindingIPs asignadas, MACs y fecha de expiración
show ip dhcp poolPools configurados e IPs utilizadas
NAT / PAT — salida a Internet
Router
ip nat insideMarca la interfaz como interna (red privada)
ip nat outsideMarca la interfaz como externa (Internet)
access-list 1 permit 192.168.0.0 0.0.255.255Define qué direcciones internas serán traducidas
ip nat inside source list 1 interface g0/1 overloadActiva PAT: IPs privadas comparten la IP pública de g0/1
show ip nat translationsTraducciones activas (IP privada ↔ IP pública)
