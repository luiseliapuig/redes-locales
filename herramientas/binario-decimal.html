Conversor binario ↔ decimal

Dos formas de representar el mismo valor.

Conversor

Escribe un valor en cualquiera de los dos campos. La otra representación se actualizará automáticamente.

Valor posicional del binario

Escribe un valor para ver la contribución de cada bit.

¿Qué representan?

El sistema decimal es el sistema habitual de base 10. El sistema binario utiliza únicamente 0 y 1 y es fundamental en informática. Ambos campos muestran el mismo valor expresado en bases diferentes.
